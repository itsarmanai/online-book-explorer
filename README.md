# Online Book Explorer

This repository contains the initial project structure for the Online Book Explorer full-stack academic project.

## Project Title
Online Book Explorer

## Purpose
A full-stack web application for browsing, searching, filtering, and managing a catalog of books. It demonstrates the full lifecycle of a Java-based application using React.js, Spring Boot, and MySQL.

## Planned Stack
- Frontend: React.js, HTML5, CSS3, Bootstrap 5
- Backend: Java 17, Spring Boot, Spring Web, Spring Data JPA
- Database: MySQL
- Tools: Maven, Git, GitHub, npm
